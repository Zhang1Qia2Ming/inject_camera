# RAW12 10Hz to 30Hz Frame Repetition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 前远和后视每个10Hz源帧连续发送三次，前广30Hz源帧保持逐帧发送，同时三路物理输出维持30Hz。

**Architecture:** 用独立纯函数维护当前源帧位置和重复计数，发送线程只在完整帧写入成功后推进状态。lane0/lane2倍率为3，lane1倍率为1；RAW文件、FPGA和域控均不修改。

**Tech Stack:** C++17、`std::thread`、XDMA字符设备、assert测试。

## Global Constraints

- 每次 `write()` 仍为 `12,441,600` 字节。
- 输出节拍仍为 `33,333,333ns`。
- lane0/lane2重复倍率固定为3，lane1固定为1。
- 写失败时不推进源帧状态。
